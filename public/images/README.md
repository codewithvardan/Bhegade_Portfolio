# Portfolio images

Place image files in this folder (`public/images/`).

| File | Used for |
| --- | --- |
| `hero.png` | Hero portrait (included) |
| `family.jpg` | Optional family photograph |

## Tips

1. Keep filenames exactly as listed above, or update `data/images.ts` to match your filenames.
2. Prefer JPG or PNG. Paths start with `/images/...` because Next.js serves `public/` at the site root.
3. If a file is missing, the page shows a clean placeholder with the label from `data/images.ts`.
4. Edit `alt` text and placeholder labels in `data/images.ts` when you add real photos.
